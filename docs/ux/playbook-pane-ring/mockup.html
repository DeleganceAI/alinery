How playbooks work

A playbook is a fixed sequence of steps. Each step reads and writes named markdown files, and some steps wait for you.

How work moves

  • Auto-advance

    Moves on when the step’s output is validated.

  • Human checkpoint

    Pauses for you to review or comment before continuing.

  • Parallel agents

    Runs an agent per artifact, then brings their results together.
