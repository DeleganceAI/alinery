# One-shot PR Prep

Inputs:
- Latest/highest-numbered matching implementation artifact in `{{ARTIFACTS_DIR}}`
- `{{TICKET_FILE}}`

If `{{REVIEW_HANDOFF_FILE}}` is non-empty and the file exists, read it with the implementation artifact.
Treat it as explicit review input/provenance for this phase. If `{{PROMPT_EXTRA}}` is non-empty,
incorporate those extra instructions.

Inspect `git status` and changed files in `{{WORKTREE}}`. Run the verification commands named by the
implementation artifact when feasible. Prepare PR title/body/test evidence. Do not claim a PR was opened
unless you actually opened one.

Write `{{ARTIFACT_FILE}}` with:
- **PR title**
- **PR body**
- **Changed files**
- **Verification**: exact commands run and results
- **Risks / follow-ups**
